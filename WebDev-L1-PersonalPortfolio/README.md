
# Nelly Sibiya – Personal Portfolio

## Project Overview

This personal portfolio website was developed by Nelly Sibiya as part of the Oasis Infobyte Web Development & Designing Internship – Level 1, Task 2.

The portfolio showcases my background as an IT student, my technical skills, development projects and contact information.

Its purpose is to introduce me professionally and document my journey towards becoming a Full-Stack Developer.

## Technologies Used

- HTML5 – Website structure and semantic content.
- CSS3 – Styling, layouts, colours and responsive design.
- CSS Grid and Flexbox – Page layout and element alignment.
- Visual Studio Code – Code editor.
- Live Server – Local website preview.
- GitHub – Project version control and hosting of source code.

## Website Features

- Professional hero section introducing Nelly Sibiya.
- Professional title: Aspiring Full-Stack Developer.
- Professional profile photo.
- About Me section describing my background and career interests.
- Technical skills section displaying my current skills and tools.
- Projects section showcasing two development projects.
- GitHub link to the completed ÉLAN STUDIO Fashion Landing Page.
- GitHub link to the completed Temperature Converter Website.
- Contact section containing my email and GitHub profile.
- Smooth scrolling navigation between website sections.
- Consistent colour palette and typography.
- Responsive layout for desktop, tablets and mobile devices.

## How to Run the Project

1. Download or clone the OIBSIP repository.
2. Open the WebDev-L1-PersonalPortfolio folder in Visual Studio Code.
3. Open index.html.
4. Right-click the file and select Open with Live Server.
5. The portfolio website will launch in your default browser.

## Design Concept

The portfolio uses a modern, minimalist and professional design.

The colour palette combines warm ivory, charcoal, muted gold and soft beige to create a clean and elegant appearance.

Georgia and Arial typography are used to establish a visual distinction between headings and body content.

The design aims to communicate professionalism, creativity and an interest in technology.
