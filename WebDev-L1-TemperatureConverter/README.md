
# Temperature Converter Website

## Project Overview

The Temperature Converter is a responsive web application developed by Nelly Sibiya as part of the Oasis Infobyte Web Development & Designing Internship – Level 1, Task 3.

The application allows users to convert temperatures between Celsius, Fahrenheit and Kelvin. It provides a user-friendly interface, input validation and automatic scrolling to display conversion results.

## Technologies Used

- HTML5 – Website structure and content.
- CSS3 – Styling, layouts, colours and responsive design.
- JavaScript – Temperature calculations, input validation and interactive functionality.
- Visual Studio Code – Code editor.
- Live Server – Local website preview.
- GitHub – Source code management.

## Website Features

- Numeric temperature input field.
- Input unit selector for Celsius, Fahrenheit and Kelvin.
- Conversion into all three temperature units simultaneously.
- Convert Temperature button.
- Reset button to clear the input and results.
- Automatic scrolling to the results after successful conversion.
- Input validation with user-friendly error messages.
- Absolute-zero validation for all three temperature units.
- Results displayed with correct unit labels.
- Responsive design for desktop, tablets and mobile devices.
- Modern temperature-inspired background image.
- Colour-coded result cards for Celsius, Fahrenheit and Kelvin.

## Temperature Conversion Formulas

**Celsius to Fahrenheit**

°F = (°C × 9/5) + 32

**Fahrenheit to Celsius**

°C = (°F − 32) × 5/9

**Celsius to Kelvin**

K = °C + 273.15

**Kelvin to Celsius**

°C = K − 273.15

## How to Run the Project

1. Download or clone the OIBSIP repository.
2. Open the WebDev-L1-TemperatureConverter folder in Visual Studio Code.
3. Open index.html.
4. Right-click the file and select Open with Live Server.
5. The Temperature Converter will open in your default browser.

## Design Concept

The website uses a modern temperature-inspired visual identity.

The design combines midnight navy with vibrant orange, coral, electric blue and purple accents. These colours represent different temperature units and create a distinctive visual experience.

The background image reinforces the relationship between heat and cold, while the white converter panel maintains readability and usability.

The interface is designed to be accessible, responsive and easy to use across different screen sizes.
