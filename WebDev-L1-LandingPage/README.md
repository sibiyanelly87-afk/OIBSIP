# ÉLAN STUDIO — Fashion Landing Page

## Project Overview

ÉLAN STUDIO is a modern fashion brand landing page created as part of the Oasis Infobyte Web Development and Designing Internship — Level 1, Task 1.

The website showcases a fictional fashion brand through an elegant, minimalist design. It uses a neutral colour palette, editorial fashion imagery and responsive layouts to provide a clean browsing experience.

## Technologies Used

- HTML5 — website structure and content.
- CSS3 — styling, layouts, colours and responsive design.
- Visual Studio Code — code editor.
- Live Server — local website preview.

## Website Features

- Sticky navigation bar with Home, Collection and About links.
- Hero section with a headline, description and call-to-action button.
- Featured collection containing three fashion cards.
- About section describing the brand's philosophy.
- Footer with social media and email links.
- Consistent neutral colour palette.
- Responsive layout using CSS Grid and Flexbox.
- Mobile-friendly design using CSS media queries.
- Smooth scrolling and interactive hover effects.

## How to Run the Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. The website will launch in your default browser.

## Testing

The website was tested in a desktop browser and mobile responsive preview.

The navigation links, call-to-action buttons, sticky navigation and fashion images were checked.

## Design Concept

ÉLAN STUDIO uses a minimalist luxury fashion aesthetic. Cream, charcoal and neutral beige tones create a sophisticated visual identity, while serif headings and clean body typography give the website an editorial feel.
